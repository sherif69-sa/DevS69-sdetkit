# Formatter policy proposal evidence

This directory retains reviewed formatter policy proposal observation sources.

`reviewed-observations.v1.json` retains one digest-bound review of the PR 2141 formatter-only proposal. Additional records may be added only after a real formatter policy proposal is reviewed and its exact proposal artifact is retained at a repository-owned path with a matching SHA-256 digest.

Synthetic test fixtures must not be copied into this evidence directory.
